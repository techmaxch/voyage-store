# Voyage Store

Временная витрина: iPhone и техника. Тёмный дизайн в стиле прототипа Voyage Mobile, две страницы (главная с брендами и каталог с фильтром по брендам), русский и английский, цены в AED и USD, заказ через WhatsApp, Telegram и Instagram. Каталог и цены берутся из Google Таблицы.

## Что менять в самом сайте

Тексты, часы работы, условия доставки и оплаты лежат в начале скрипта в `public/index.html`, блок `TEXTS` (`T.ru` и `T.en`). Стоимость доставки в AED: `DELIVERY_AED`. Цвета: переменные в начале стилей (`--primary` и другие).

## Как это устроено

```
Google Таблица (опубликована как CSV)
        │  читает сервер, кэш 60 сек
        ▼
server.js  ──  /api/catalog  ──►  public/index.html (сайт)
   │
   └── если таблица недоступна: data/products.json (запасной каталог)
```

Зависимостей нет, нужен только Node.js 18 или новее.

## Структура проекта

| Файл | Что это |
|---|---|
| `server.js` | сервер: отдаёт сайт и каталог из таблицы |
| `public/index.html` | сайт (дизайн, переключатели RU/EN и AED/USD) |
| `public/images/` | фото товаров, брендов и первого экрана |
| `data/products.json` | запасной каталог |
| `template/products-template.csv` | шаблон Google Таблицы |
| `.env.example` | список настроек (переменных) |

## Шаг 1. Google Таблица

1. Откройте [sheets.new](https://sheets.new) и создайте таблицу. Назовите её, например, `Voyage Store: каталог`.
2. Файл → Импортировать → Загрузить → выберите `template/products-template.csv` → «Заменить текущий лист». Если таблица разъехалась по столбцам, в окне импорта выберите разделитель «Запятая».
3. Заполните свои товары (столбцы описаны ниже).
4. Файл → Поделиться → **Опубликовать в Интернете** → выберите нужный лист, формат **Значения, разделённые запятыми (.csv)** → «Опубликовать». Скопируйте ссылку.

> Опубликованная таблица открыта всем, у кого есть ссылка. Заведите отдельную таблицу только для витрины и не храните в ней закупочные цены и личные данные.

### Столбцы

Первая строка с названиями столбцов обязательна, названия не менять.

| Столбец | Обязательно | Что писать |
|---|---|---|
| `id` | да | Короткий уникальный код латиницей, без пробелов: `ip17`. Он же имя фото: `images/ip17.jpg` |
| `brand` | нет | Бренд: `Apple`, `Samsung`, `Dyson`. По нему строятся карточки брендов и фильтр в каталоге. Писать всегда одинаково |
| `category` | нет | Тип товара латиницей: `smartphone`, `headphones`, `styler`, `watch`, `tablet`, `tv`, `vacuum`, `speaker`, `accessory`, `laptop`, `console`. Любое другое слово покажется как есть |
| `name_ru` / `name_en` | да (хотя бы одно) | Название на русском и английском. Если заполнено одно, оно же показывается в обоих языках |
| `spec_ru` / `spec_en` | нет | Короткое описание (память, цвет). Попадает в текст заказа |
| `price_aed` | нет | Цена в дирхамах числом, без валюты. **Пусто = «Цена по запросу».** Доллары считаются автоматически по курсу |
| `in_stock` | нет | `да` или пусто: «В наличии». `под заказ`: «Доступен к заказу» (цена показывается с «от»). `нет`: «Нет в наличии» |
| `image` | нет | Пусто: берётся `images/<id>.jpg`. Можно имя файла из папки images или полная ссылка `https://...` |

Товары с `нет` остаются в каталоге с пометкой «Нет в наличии». Чтобы убрать товар совсем, удалите его строку. Порядок строк = порядок на сайте.

Изменения в таблице появляются на сайте примерно через минуту. Публикацию заново делать не нужно.

## Шаг 2. GitHub

1. Создайте на [github.com/new](https://github.com/new) пустой репозиторий (например `voyage-store`, можно приватный).
2. В папке проекта выполните:

```bash
git init
git add .
git commit -m "Voyage Store: первая версия"
git branch -M main
git remote add origin https://github.com/ВАШ_АККАУНТ/voyage-store.git
git push -u origin main
```

Файл `.env` с настройками в репозиторий не попадает (он в `.gitignore`).

## Шаг 3. Railway

1. На [railway.com](https://railway.com) → New Project → **Deploy from GitHub repo** → выберите `voyage-store` (при первом разе разрешите Railway доступ к репозиторию).
2. Railway сам определит Node.js и запустит `npm start`. Ничего настраивать для сборки не нужно.
3. Откройте сервис → вкладка **Variables** → добавьте переменные:

| Переменная | Значение |
|---|---|
| `SHEET_CSV_URL` | ссылка на опубликованную таблицу из шага 1 |
| `WHATSAPP` | номер с кодом страны, без `+` и пробелов, например `971501234567` |
| `TELEGRAM` | ник без `@` |
| `INSTAGRAM` | ник без `@` |
| `USD_RATE` | `3.65` (при необходимости другой) |

После сохранения Railway перезапустит сервис сам.

4. Вкладка **Settings → Networking → Generate Domain**: получите временную ссылку вида `...up.railway.app`. Проверьте, что сайт открывается.

---

## Шаг 4. Свой домен

1. Railway → сервис → **Settings → Networking → Custom Domain** → введите ваш домен или поддомен (например `shop.вашдомен.com`).
2. Railway покажет, какую запись добавить в DNS (обычно `CNAME`). Добавьте её у регистратора домена (раздел DNS).
3. Подождите от нескольких минут до пары часов. HTTPS-сертификат Railway выдаст сам.

Для основного домена без поддомена (`вашдомен.com`) у некоторых регистраторов CNAME недоступен. Тогда проще использовать поддомен (`shop.`, `store.`) или перенести DNS на Cloudflare.

## Фото товаров

Положите файлы в `public/images/` и отправьте изменения на GitHub, Railway обновит сайт сам. Имена файлов:

| Файл | Где показывается |
|---|---|
| `<id>.jpg` (например `ip17.jpg`) | карточка товара в каталоге |
| `brand-<бренд>.jpg` (например `brand-apple.jpg`, `brand-google-pixel.jpg`) | карточка бренда на главной |
| `hero.jpg` | большое фото на первом экране |

```bash
git add .
git commit -m "Добавил фото"
git push
```

Лучше всего подходят квадратные снимки на светлом фоне, до 200-300 КБ. Используйте только свои фото или официальные материалы поставщика: чужие картинки из интернета могут нарушать права. Если фото нет, показывается серая заглушка «Фото». Фото на светлом фоне смотрятся лучше всего: на сайте они лежат на светлой подложке.


## Частые вопросы

- **Цена не обновилась.** Подождите минуту. Проверьте, что таблица опубликована, а ссылка в `SHEET_CSV_URL` именно на CSV (в ссылке есть `output=csv`).
- **На сайте старые тестовые товары.** Это запасной каталог: таблица не подключена или недоступна. Проверьте `SHEET_CSV_URL` и обязательные столбцы. Причину сервер пишет в логи Railway (вкладка Deployments → View Logs).
- **Товар пропал.** Проверьте столбец `in_stock`: значение `нет` скрывает товар. Строки без `id` или цены тоже пропускаются.
- **Курс.** Меняется переменной `USD_RATE`, доллары на сайте округляются до целых.
- **Telegram и Instagram не подставляют текст заказа.** Эти мессенджеры так не умеют: сайт копирует текст в буфер, клиент вставляет его в чат. WhatsApp подставляет текст сам.
