Фото лежат в этой папке, без подпапок. Формат .jpg, имена строчными буквами.

  hero.jpg              большое фото на первом экране главной
  cat-iphone.jpg        карточки категорий на главной
  cat-ipad.jpg
  cat-mac.jpg
  cat-airpods.jpg
  cat-watch.jpg
  cat-tv.jpg
  <id>.jpg              фото товара, id из первого столбца таблицы (например ip17-256.jpg)

Другое имя файла или ссылку https://... можно указать в столбце image таблицы.
Если файла нет, на сайте показывается серая заглушка «Фото».
